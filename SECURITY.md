# Security Policy

## Supported Versions

Security fixes are accepted for the current `main` branch until tagged releases
define a longer support window.

## Reporting a Vulnerability

Report suspected vulnerabilities through GitHub Security Advisories on the
repository. Do not disclose exploitable details publicly before maintainers have
had time to triage and prepare a fix.

## Dependency Updates

Runtime dependencies are intentionally small. Optional developer and documentation
dependencies should be updated regularly and reviewed through CI.

## Disclosure Policy

Maintainers should acknowledge reports, assess severity, prepare a fix, and
publish release notes that describe impact and remediation without exposing
unnecessary exploit detail.
